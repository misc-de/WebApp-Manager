WebApp Manager builds on these open-source projects and services. Thanks to
everyone who builds and maintains them. Each keeps its own licence; WebApp
Manager itself is released under the [MIT License](LICENSE).

| Project | Used for | Licence |
|---|---|---|
| [GTK 4](https://www.gtk.org/) · [libadwaita](https://gitlab.gnome.org/GNOME/libadwaita) | user interface | LGPL-2.1+ |
| [GLib / GIO](https://gitlab.gnome.org/GNOME/glib) · [Pango](https://gitlab.gnome.org/GNOME/pango) · [GdkPixbuf](https://gitlab.gnome.org/GNOME/gdk-pixbuf) | platform, text, icon loading | LGPL-2.1+ |
| [PyGObject](https://pygobject.gnome.org/) | Python bindings for GTK/GLib | LGPL-2.1+ |
| [Pillow](https://python-pillow.org/) | icon conversion and scaling | MIT-CMU |

| [CairoSVG](https://cairosvg.org/) (optional) | SVG icon import | LGPL-3.0+ |
